# Internationalisation

3omar prend en charge `fr`, `en`, `ar` et `es`. Le français est la langue par défaut et de repli.

## Architecture

- `config/app.php` définit les locales supportées, leurs libellés courts et leur direction (`ltr`/`rtl`).
- `SetLocale` (middleware) applique la langue conservée en session à chaque requête.
- `LocaleController` valide le changement de langue et redirige vers la page précédente (même hôte uniquement).
- `lang/{locale}/ui.php` contient tous les messages d'interface.
- Le layout définit automatiquement les attributs `lang` et `dir` sur `<html>` ; l'arabe active le rendu RTL via CSS.

## Ajouter ou modifier un message

1. Choisir une clé stable, par exemple `ui.result.mon_libelle`.
2. L'ajouter dans les **quatre** catalogues (`lang/fr`, `en`, `ar`, `es`).
3. Ne pas utiliser le texte français comme clé.
4. Ne pas dupliquer de valeurs chiffrées — utiliser `config('payroll.*')` depuis les vues.

## Limites actuelles

Les parcours principaux sont traduits dans les quatre langues. Le détail réglementaire, les avertissements du moteur et le formatage localisé des nombres (séparateurs) restent à migrer progressivement. Toute nouvelle interface doit être traduite dans les quatre langues dès sa création.
