# Internationalisation

3omar prend en charge `fr`, `en`, `ar` et `es`. Le français est la langue par défaut et de repli.

## Architecture

- `config/app.php` définit les locales, libellés courts et directions.
- `SetLocale` applique la langue conservée en session.
- `LocaleController` valide le changement demandé.
- `lang/{locale}/ui.php` contient les messages d'interface.
- Le layout définit automatiquement `lang` et `dir`; l'arabe active le rendu RTL.

## Ajouter ou modifier un message

Utiliser une clé stable, par exemple `__('ui.result.details')`, puis renseigner cette clé dans les quatre catalogues. Ne pas utiliser le texte français comme clé.

## Libellés métier

Les paramètres chiffrés restent dans `config/payroll.php`. Les futurs libellés métier doivent utiliser une clé comme `label_key => payroll.allowances.transport`, traduite dans chaque catalogue, sans dupliquer les taux ou plafonds.

## Limites actuelles

Les parcours structurants et le shell sont traduits. Le détail réglementaire, les libellés métier, les avertissements du moteur et le formatage localisé des nombres restent à migrer progressivement. Toute nouvelle interface doit être traduite dans les quatre langues dès sa création.
