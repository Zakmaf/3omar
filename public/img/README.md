# Assets de marque 3omar

Ce dossier est la **source de vérité** des déclinaisons officielles du logo.
Toute version absente de ce dossier n'existe pas officiellement (voir
`docs/charte-graphique-editoriale.html`, section 02).

| Fichier | Usage |
|---|---|
| `logo.svg` | Logotype principal, source vectorielle |
| `logo_header_200x50.png` / `400x100` / `800x200` | Logotype horizontal — navbar, en-têtes (1×/2×/4×) |
| `logo_banner_1200x630.png` | Bannière Open Graph / réseaux sociaux |
| `app_icon_16.png` → `app_icon_1024.png` | Icône application — favicon, apple-touch-icon, PWA, stores |

Règles d'usage : fond clair uniquement pour le logotype (il n'existe pas de
version inversée blanche) ; sur fond foncé, utiliser l'icône application ou le
wordmark typographié « 3omar » en Outfit 700.
